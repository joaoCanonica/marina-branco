## Achado
Termo guarda-chuva para conjuntos de procedimentos faciais (preenchimentos, medicamentos injetáveis, bioestimuladores). Não há um procedimento único a descrever nem base de evidência própria; cada componente tem riscos e, alguns, envolvem medicamento de prescrição (que o site não pode anunciar). No Brasil, o CFO reconhece "harmonização orofacial" como especialidade odontológica — **CONFIRMAR resolução vigente** caso a executora seja cirurgiã-dentista.
